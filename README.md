# Style Bites Interiors website

Static, multi-page website using plain HTML, CSS and JavaScript.

## Structure
- `index.html`, `about.html`, `products.html`, `order.html`, `contact.html`
- `css/styles.css`
- `js/main.js`, `js/products.js`
- `assets/` supplied product photography, sample price poster, supplied Style Bites Interiors PNG logo, and logo PDF

Open `index.html` in a browser or publish the folder to a static web host. No build step is required. Forms post to FormSubmit at `sales@stylebitesinteriors.co.ke`; activate the recipient using FormSubmit's first-submission email if prompted. WhatsApp opens a chat with +254 756 378 809. Inventory prices reflect the supplied list and should be confirmed with Style Bites before purchase.
